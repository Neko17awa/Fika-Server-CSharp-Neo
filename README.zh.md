# Fika-Neo · 服务端

[English](README.md) · [中文](README.zh.md)

[project-fika/Fika-Server-CSharp](https://github.com/project-fika/Fika-Server-CSharp) 的非官方 C# SPT.Server **服务端**分支。

配套客户端：[Fika-Plugin-Neo](https://github.com/Neko17awa/Fika-Plugin-Neo)。

**这不是官方 Fika。** 与 [Project Fika](https://github.com/project-fika)、[SP-Tarkov](https://sp-tarkov.com/)、Battlestate Games 均无隶属、赞助或代言关系。需要受支持的联机方案时，请使用官方服务端模组和 [Fika Wiki](https://wiki.project-fika.com/)。

## 与上游的关系

Fika-Neo 以官方 Fika-Server-CSharp **v2.4.1**（`a6bbfb54`）为起点。`neo` 是独立的非官方修改线，**不会再与上游保持全量同步。** 默认不合并官方后续更新；若以后局部采用上游代码，会作为修改单独标明。

`main` 只保留导入时的官方快照。开发在 **`neo`** 上进行。
