## Divergence

Fika-Neo started from official Fika-Server-CSharp **v2.4.1** (`a6bbfb54`). The `neo` branch is an independent unofficial line. **It will not stay in full sync with upstream.** Official updates are not merged by default; any later reuse of upstream code will be selective and called out as a modification.

`main` is only the import snapshot of the official tree. Work happens on **`neo`**.
